# 赛后智能复盘 Demo

直接双击 `index.html` 即可运行，无需安装任何依赖。

## 功能

- 展示完赛人数、完赛率、平均完赛时间、医疗处置和满意度。
- 展示各赛段通过人数。
- 展示 AI 识别的重点问题与建议。
- 自动生成复盘报告初稿并支持复制。
- 支持导入纵向 CSV 数据，可使用目录内的 `示例数据.csv` 测试。

## CSV 格式

第一列为 `metric`，第二列为 `value`。必须包含 `registered` 和 `finishers`；其他支持字段包括 `avgTime`、`medical`、`satisfaction`、`km5`、`km10`、`half`、`km30`、`km35`。

当前版本为无后端演示，报告生成使用预设规则。正式产品可进一步接入大模型、计时系统、医疗台账、补给记录、调查问卷和舆情数据。
