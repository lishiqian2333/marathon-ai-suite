# 鹏飞马拉松宣传智能助手演示脚本

## 演示定位

- 演示对象：赛事主办方、品牌方与项目决策者。
- 核心故事：一份赛事资料，生成公众号文案、宣传视频、合作 PPT 与文创设计，并保持事实和品牌口径一致。
- 默认时长：5 分钟。
- 产品边界：当前版本是稳定演示系统，部分 AI 生成过程采用高质量预设成果；正式项目可接入模型、文档解析和业务系统。
- 推荐环境：1920×1080、浏览器缩放 100%、开启声音；核心流程可离线运行。

## 演示前准备

1. 运行 `npm run demo:check`，确认全部检查通过。
2. 打开首页并刷新一次，依次确认四个模块可以切换。
3. 确认 8 张视频图片、成片、PPT 预览和 PPT 下载文件正常。
4. 关闭通知与无关窗口，将浏览器缩放设为 100%。
5. 在本地准备导出的 PPT、成片文件和最近一次标准录屏。
6. 不在现场修改代码；发生异常时按本文“应急切换”处理。

## 固定开场

> 今天演示的不是一个单点文案工具，而是一套赛事宣传内容生产工作台。平台基于同一份赛事资料，统一理解赛事事实、品牌定位和公益主题，再生成公众号文案、宣传视频、合作 PPT 与文创设计成果。

## 5 分钟标准版

### 0:00—0:35｜产品定位

- 操作：停留在公众号工作台首页。
- 讲解：传统赛事宣传由多个团队分别生产，容易出现资料重复整理、口径不一致和修改链路过长。平台将同一份赛事资料转化为多类成果。
- 成功信号：客户理解核心价值是“统一资料与批量生产”，而不只是写文案。
- 过渡语：先看最常用的公众号宣传场景。

### 0:35—1:45｜公众号宣传

- 操作：点击“赛事官宣”，展示赛事名称、主口号以及空缺的日期、规模；生成文章；切换一次风格；依次展示标题推荐、信息核查和一稿多用。
- 讲解：AI 只使用已确认事实。日期、人数和项目尚未提供，因此系统保留空缺并提示审核，不会自行编造。
- 成功信号：出现完整正文和 5 个标题；未知事实没有变成具体日期或数字；朋友圈文案可以复制。
- 过渡语：同一套赛事主题还可以继续转化为短视频内容。

### 1:45—2:35｜照片生成视频

- 操作：进入视频模块；导入演示照片；展示素材识别；点击生成；成片出现后播放 5—8 秒。
- 讲解：AI 会理解起跑、群像、人物情绪和冲线场景，并按“出发—坚持—抵达”组织节奏。
- 成功信号：8 张素材正常显示，进度到达 100%，视频可以播放和导出。
- 过渡语：面向品牌决策层，同一份资料还需要转换成合作汇报逻辑。

### 2:35—3:45｜合作 PPT

- 操作：进入 PPT 模块；生成提纲；确认生成；定位品牌合作价值；切换领导版；生成当前页演讲备注；展示下载入口。
- 讲解：AI 不只是排版，而是针对鹏飞集团决策层组织“赛事价值—品牌契合—权益—传播—合作建议”的说服结构。
- 成功信号：提纲与配置页数一致，预览、翻页、领导版和下载入口正常。
- 过渡语：最后看赛事主题如何沉淀成统一的视觉资产。

### 3:45—4:35｜文创设计

- 操作：进入文创模块；指出城市文化为演示预设；生成方案；展示三条设计方向；切换奖牌、T 恤、吉祥物和海报；打开一张大图。
- 讲解：AI 将赛事理念、企业品牌、公益主题和城市文化转译成统一的产品视觉语言。
- 成功信号：三条方向和四类产品正常，图片清晰，“演示预设”提示可见。

### 4:35—5:00｜固定收尾

> 从公众号、视频、合作 PPT 到文创设计，所有成果都来自同一份案例资料。正式产品接入真实模型和赛事知识库后，还可以继续加入资料上传、内容审核、版本管理和团队协作。

## 3 分钟领导速览版

1. 0:00—0:30：使用固定开场，只讲“一份资料生成整套成果”。
2. 0:30—1:10：公众号选择“赛事官宣”，生成文章并展示信息核查；不切换多个风格。
3. 1:10—1:50：PPT 直接生成并定位品牌合作价值页，展示领导版。
4. 1:50—2:30：文创快速切换四类产品；不等待完整动画。
5. 2:30—3:00：使用固定收尾。

三分钟版本不播放完整视频、不演示历史恢复、不进入 PPT 全屏。

## 8 分钟完整版

在 5 分钟版本基础上增加：

1. 用自然语言创建一次宣传任务，再演示“更正式”“精简”和历史版本恢复。
2. 完整展示信息核查和渠道改写。
3. 播放完整宣传视频，并切换横竖屏展示。
4. 演示 PPT 全屏、键盘翻页、关键词定位和演讲备注。
5. 解释三条文创方向的差异，并逐一查看四类产品。
6. 用 30 秒说明真实能力与演示预设的边界。

## 应急切换

| 异常 | 立即动作 | 讲解口径 |
|---|---|---|
| 页面无法打开 | 播放最近一次标准录屏 | “这里展示一次完整的标准流程。” |
| 生成动画卡住 | 跳到下一个模块，不现场排查 | 继续讲成果价值 |
| 视频无法播放 | 展示素材识别页，再打开本地成片 | 强调素材理解与叙事结构 |
| PPT 预览空白 | 直接打开导出的 PPT | 按正常汇报路线继续 |
| 下载入口异常 | 打开预先准备的成果文件夹 | 展示已有交付物 |
| 大屏显示不全 | 将浏览器缩放调整到 90% | 优先保证三栏完整 |
| 临时断网 | 继续本地流程 | 核心演示不依赖现场网络 |
| 时间临时压缩 | 立即切换 3 分钟版 | 跳过视频生成过程 |

现场原则：不调试、不解释技术错误，直接切换到可用成果。
