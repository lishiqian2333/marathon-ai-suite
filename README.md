# Marathon AI Suite

面向马拉松赛事全流程运营的 AI Demo 套件，覆盖赛前宣传、赛事咨询与赛后复盘。

## 项目模块

- `赛事宣传智能助手demo/`：基于赛事资料生成宣传内容的 Web Demo。
- `智能客服demo/`：面向赛事咨询场景的智能客服 Web Demo。
- `赛后智能复盘demo/`：导入赛事数据，展示指标、问题诊断与复盘报告。

仓库根目录同时收录方案文档、开发任务书和演示素材，便于理解业务背景与后续扩展。

## 本地运行

两个 Web 项目均要求 Node.js `>=22.13.0`：

```bash
cd 智能客服demo # 或：cd 赛事宣传智能助手demo
npm install
npm run dev
```

赛后智能复盘 Demo 无需安装依赖，直接打开 `赛后智能复盘demo/index.html` 即可。

## 当前定位

本项目用于方案展示与现场演示，部分 AI 生成和数据分析能力采用预设内容或规则模拟。生产化时可继续接入大模型、赛事业务系统及真实数据源。
